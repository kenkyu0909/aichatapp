## 再開・安全性

実験JSONと一時SQLiteは保存され、秘密値はJSON、HTML、ログへ書き込んでいない。スクリプトは実際に送った候補だけを送信数に加算し、上限20通をプログラムで拒否する。APIエラー後は `scripts/simulate_conversation.py --resume --api-dir <APIフォルダー>` で再開できる。一時SQLite/JSONが一致しなければ停止する。SQLite書込後・JSON更新前にプロセスが強制終了した場合の自動復旧は未実装。一時SQLiteとJSONの履歴が一致しない場合は再開を拒否する。

このレポート作成時点でAPI1の認証/権限の根本原因、APIプロジェクトの課金状態、無料枠・残り割当は特定できていない。API2への自動移行も未検証。
