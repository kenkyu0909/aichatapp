## 再現した問題と修正

1. 候補の本人事実検査で、最近の読書/視聴、カフェの好み、買い物習慣、カレー経験、旅行、居住地、休日、パンなどの未確認主張が漏れるケースを追加して検出するようにした。
2. 相手への疑問文を本人の一人称事実として誤判定しないようにした。句読点を除いた文境界で映画の質問を誤処理する回帰も発見し、原文の文境界を保った検査に修正した。
3. 最近の本/映画、旅行頻度/最近の旅行、カフェの好み、料理習慣、会う場所/予定を分けて、本人への確認質問の粒度を合わせた。
4. 既知の「週末は友達とカフェへ行く頻度」を言い換えて聞く候補を拒否し、店名・雰囲気・おすすめなどの深掘りは許容した。
5. 固定ケースで「週末は友達と出かけますか」と「普段料理はしますか」の回答粒度が広すぎる点も見つけ、確認質問をより直接的にした。
