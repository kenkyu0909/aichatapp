# Message Mate — ローカル恋愛メッセージ支援アプリ

**Windows PC専用・本人だけが使うローカルWebアプリ**です。自分のプロフィールと相手の情報・会話を保存し、Gemini APIで返信候補とメッセージ付きいいねを3案ずつ提案します。

## できること

- 自分のプロフィールと、避けたい言い回しを登録
- マッチした相手を名前、自由記述プロフィール、任意の識別用写真で登録
- 相手別に会話履歴を追加・編集・削除
- 会話を踏まえた返信：おすすめ1案＋方向性の異なる2案、短い理由
- マッチ前の相手プロフィールからメッセージ付きいいねを3案提案
- 候補をコピーし、**実際に送信した文章だけ**編集して履歴に記録
- APIキーがなくてもデータ保存や画面操作を試せるデモモード（**デモ候補は固定例文で文脈を読んでいません**）

マッチングアプリへの自動ログイン・自動送信・画像認識機能はありません。

## Windowsでの起動方法

1. [Python 3.11以上](https://www.python.org/downloads/windows/)をインストールします（インストール画面で Add python.exe to PATH を推奨）。
2. リポジトリをZIPダウンロードして、任意のフォルダに解凍します。またはGitでクローンします。
3. **start.bat** をダブルクリックします。初回はPython仮想環境の作成とライブラリのインストールを行います。
4. ブラウザで **http://127.0.0.1:8765** を開きます。終了するには起動中の黒い画面で Ctrl+C を押します。
5. 自分のプロフィールを保存し、相手を登録して使用してください。

APIキーがない場合も画面とDBは使えますが、AI候補は固定のサンプルです。実際のAI生成には以下の設定が必要です。

## Gemini APIの設定（無料枠を利用する場合）

1. [Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを作成し、**無料枠の対象となるモデルとプロジェクトか**事前に確認します。
2. 初回起動で自動作成される **.env** をメモ帳で開き、GEMINI_API_KEY= の右側にキーを貼り付けて保存します。
3. start.bat を終了して再起動します。左下の「デモモード」がモデル名に変われば設定を読み込んでいます。
4. モデルを変更する場合は .env の GEMINI_MODEL を編集します。初期値は **gemini-3.5-flash-lite** です。

無料利用回数はモデルやプロジェクトで異なり、1日1,000回の固定保証はありません。[公式料金](https://ai.google.dev/gemini-api/docs/pricing)と[AI Studioのレート制限](https://aistudio.google.com/rate-limit)を確認してください。アプリはモデルや利用枠を有料プランへ自動切替しません。**既に課金が有効なGoogleプロジェクトを選んだ場合の料金まではアプリで判定・防止できません。**

### プライバシー

- 待受アドレスは **127.0.0.1** 固定です。外部公開用のサーバーやログイン機能はありません。
- 自分や相手のプロフィール、会話履歴を含むデータは **data/app.sqlite3** に、写真は **data/photos/** に保存します。どちらもGitの追跡対象から除外しています。
- **AI生成時は、本人のプロフィールと相手の名前・プロフィール文、対象の会話の直近最大60件がGemini APIへ送信されます。** 相手の写真やファイルパスは送信しません。必要に応じて相手の名前をニックネームにしてください。
- **Gemini無料枠におけるGoogleによるデータ利用条件**を確認し、個人特定情報や機密内容は入力を控えてください。
- 現在リポジトリが Public ならソースコードは公開されています。希望どおり非公開にするにはGitHubの Settings → General → Danger Zone → Change repository visibility から **Private** に変更してください。
- APIキーを保存した .env や個人データを含む data/ は**絶対にGitへコミットしない**でください。
- データをバックアップするときは、アプリを止めてから data/ フォルダを安全な場所にコピーしてください。

## 開発者向け

Python 3.11+ が必要です。start.batを使わない場合は、仮想環境を作成して requirements.txt をインストールし、次を実行してください。

~~~sh
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8765
~~~

オフラインのAPIテスト：

~~~sh
python -m pip install pytest httpx
python -m pytest -q
~~~

プロンプトは **prompts/reply.txt** と **prompts/like.txt** を編集します。入力データの構造は app.py の build_context にあります。

### 現段階での制限

- 自動送信、複数端末同期、スクリーンショット読み込み、複数画像登録はありません。
- AIの候補は提案であり、相手との関係を保証するものではありません。
- Gemini本番接続には自分のAPIキーが必要です。自動テストはデモモードとローカル操作を対象にします。
- 会話の取り込みは手動です。送信済みの文章は本人が確認し、履歴に記録してください。
